# Chen-Ueta


Chen-Ueta attractor is a non-topological equivalent to the Lorenz attractor, which contains a rich structure, containing pitchfork bifurcation and doubling period regions, as studied by Chen in 2000.

However, this work consists in implement this results an investigate the multistability properties, which contains depending on the region of parameter plane 5 attractors. The figures for this publication, are available in the folder "Fig_article", the codes are also implemented in C (final version) and fortran (preliminary version), and the figure plot was done in Python.

Some visualization of attractors separately are available in the file "curves_plot3D.ipynb", which we will name different attractors of same period using the prime sign. Moreover the fixed point of this system are represented in the figures represented in the same file. To conclude, we also display some figures at the folder "figures" which was done in the preliminary analysis.
