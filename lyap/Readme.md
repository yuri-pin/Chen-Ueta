# Calculations of Lyapunov Exponents

These are some codes that generate the bifurcation diagram of the Chen-Ueta attractor. This file intends to explain how to implement the code presented here.

After cloning this code, it is possible to run it. Then, inside the folder called `lyap` you can type ' make ' in the terminal, which will execute all the code; however, the implementation of the executable is necessary to do individually.

For this implementation, run `./executavel/exp_lyap`, which can be observed after running `make`.

Finally, the files generated by this implementation will be available in the folder `exponents`. They do not follow a clear rule of construction; however, they are for different basins of attraction.
