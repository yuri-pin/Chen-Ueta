# Calculations of Lyapunov Exponents

These are some codes which makes the bifurcations diagram of Chen-Ueta attractor. And this file intent to explain the to implement these codes presented here.

After clone this code, it is possible to run these code. Then, inside of the folder called `lyap` you can write on the terminal, `make`, where will execute all the codes, however, the implementation of executable is necessary to do individualy.

For this implementation, run `./executavel/exp_lyap`, where can be observed after run the `make`.

Finally the files, generated by this implementation will be available in the folder `exponents`. They do not follow a clear rule of construction, however they are for different basins of attraction.
