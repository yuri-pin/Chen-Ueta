# Calculations for the bifurcation diagrams and the attraction basin.

These are some codes that generate the bifurcation diagram of the Chen-Ueta attractor. This file intends to explain how to implement the code presented here.

After cloning this code, you can run it. Then, inside the folder called `bif_and_basin`, you can run `make` in the terminal, which will execute all the code; however, you need to build the executables individually.

For this implementation, run `./executavel/NAME_OF_FILE`, which can be observed after running `make`.

Finally, the files generated by this implementation will be available in the folder `csv_SIMILAR_NAME_OF_EXECUTABLE`. Instead, the files are written in binary.
